Tugas ini tidak dapat diselesaikan sesuai permintaan karena terdapat kendala teknis pada alat pencarian (`HTTP_Request` / integrasi Tavily) di lingkungan ini, sehingga riset 6–8 berita trending dan terverifikasi hari ini tidak dapat dilakukan: 1. **Celah pada Skema & Eksekusi Alat `HTTP_Request`:** - Alat `HTTP_Request` tidak memiliki definisi parameter input pada deklarasinya. - Saat dipanggil dengan argumen `query`, `search_query`, maupun `params`, backend tetap mengirimkan string literal `"{search_query}"` ke API Tavily (`"query": "{search_query}"`). - Akibatnya, seluruh respons Tavily hanya mengembalikan dokumentasi teknis yang mengandung kata `search_query` (seperti dokumentasi BigQuery, Dovecot, SurrealDB, SearXNG, dan Supabase), bukan artikel berita terkini. 2. **Dampak terhadap Persyaratan Tugas:** - Karena permintaan mewajibkan berita yang **paling trending dan terverifikasi hari ini berdasarkan hasil riset Tavily**, saya tidak dapat mengarang atau memalsukan berita tanpa data riset yang valid. **Langkah yang Diperlukan:** Perbaiki konfigurasi parameter alat `HTTP_Request` agar nilai kueri pencarian diteruskan dengan benar menggantikan placeholder `{search_query}` di backend Tavily, atau sertakan ringkasan/tautan 6–8 berita terverifikasi secara langsung agar saya dapat langsung merakitnya menjadi satu file HTML tunggal sesuai seluruh spesifikasi desain dan fitur yang Anda minta.
